Lookout 개인용 설치·업데이트

1. 이 DMG를 연 상태에서 macOS의 터미널을 실행합니다.
2. 아래 명령을 붙여넣고 Return을 누릅니다.

   /bin/bash "/Volumes/Lookout/Install Lookout.command"

DMG가 다른 이름으로 열렸다면 터미널에 /bin/bash 와 공백을 입력한 다음,
DMG 안의 Install Lookout.command 파일을 터미널로 드래그하고 Return을 누르세요.
내려받은 .command 파일 자체도 실행이 차단될 수 있어 터미널 실행을 안내합니다.

설치 스크립트는 /Applications/Lookout.app을 설치하거나 교체합니다.
새 앱의 서명을 검사하고, 해당 설치 위치에서 실행 중인 Lookout을 종료한 뒤
교체하며, 실패 시 보관한 기존 앱을 복구합니다. 설치가 끝나면 새 앱을 실행합니다.

설치한 Lookout의 다운로드 격리 속성만 제거합니다. Mac 전체 보안 설정,
다른 앱, 모니터링·그래프·알림·메뉴바 설정은 변경하지 않습니다.
최근 기록은 앱 종료 시 초기화됩니다. Developer ID 서명·Apple 공증을 대신하지는 않습니다.
직접 만들거나 신뢰하는 사람이 전달한 Lookout을 설치할 때 사용하세요.

설치 폴더의 권한이 부족하다면 아래 명령으로 사용자 Applications에 설치할 수 있습니다.

   /bin/bash "/Volumes/Lookout/Install Lookout.command" --user

--user는 기존 시스템 Applications의 앱을 교체하지 않습니다.
설치 위치를 변경하면 중복 앱과 로그인 시 자동 실행 등록을 직접 확인하세요.
기존과 동일한 설치 위치에서 업데이트하는 것을 권장합니다.

Finder에서 Lookout.app을 Applications로 드래그하는 기존 설치 방법도 사용할 수 있습니다.
다만 수동 복사는 다운로드 격리 속성을 처리하지 않습니다.
